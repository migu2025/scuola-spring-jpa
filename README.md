# Scuola Spring JPA

Progetto sviluppato con Spring Boot e Spring Data JPA per la gestione di un sistema scolastico tramite API REST.

## 🚀 Tecnologie Utilizzate

- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- REST API

---

## 📦 Funzionalità

- Gestione studenti
- Gestione corsi
- Relazioni database con JPA
- CRUD completo
- API RESTful
- Persistenza dati con MySQL

---

## 🛠️ Architettura

Il progetto utilizza:

- Controller REST
- Service Layer
- Repository JPA
- Entity Hibernate
- Database relazionale MySQL
